Stack soberano

Cuatro principios operativos

01 · Stack tecnológico
TFLite + iNaturalist fallback
Modelo local entrenado con 5.690 especies Catálogo Plantas Útiles + Kew + GBIF. Fallback iNaturalist API solo si hay WiFi y promotor lo autoriza.
02 · Datos
GeoJSON + EXIF preservado
Cada registro = JSON con coords, taxonomía Kew, foto original, audio opcional (nombre en lengua), validación promotor local.
03 · Soberanía
Servidores propios ONIC
Hosting Plataforma Soberana de Datos (Módulo 2). Cero cloud externo. Cifrado AES-256 en tránsito y reposo. CARE+FAIR principles operacionalizados.
04 · Devolución
Aprobación comunidad antes de público
App pide confirmación al Cabildo antes de sync público (GBIF/iNaturalist). El registro queda en custodia indígena hasta que el Cabildo aprueba la difusión externa.
